
# Windows-Based SOC Threat Detection & Incident Investigation Lab

## 1. Project Overview

This project focuses on building a practical Security Operations Center (SOC) environment to monitor Windows security events, detect suspicious activities, investigate potential security incidents, and document findings.

The lab uses controlled security simulations to understand how SOC analysts identify and investigate threats.

## 2. Objectives

- Understand SOC operations and security monitoring.
- Collect and analyse Windows security event logs.
- Configure a SIEM platform for log monitoring.
- Detect suspicious authentication activities.
- Investigate simulated brute-force attacks.
- Develop security detection queries.
- Automate selected log analysis tasks using Python.
- Prepare incident investigation reports.

## 3. Technology Stack

- Operating System: Windows 11
- SIEM: Splunk Enterprise
- Endpoint Monitoring: Windows Event Viewer and Sysmon
- Log Collection: Splunk Universal Forwarder
- Programming: Python
- Development Environment: Visual Studio Code

## 4. Project Status

Currently in development.

## 5. Security Disclaimer

All testing and attack simulations will be performed
within an authorised, controlled laboratory environment.
