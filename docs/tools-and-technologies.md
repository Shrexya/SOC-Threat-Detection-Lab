# SOC Lab – Tools and Technologies

| Tool | Purpose |
|---|---|
| Windows 11 | Monitored endpoint |
| Oracle VirtualBox | Runs the Ubuntu virtual machine |
| Ubuntu 24.04 | Hosts the SIEM server |
| Splunk Enterprise | Collects, indexes and analyses security logs |
| Splunk Universal Forwarder | Sends Windows logs to Splunk |
| Windows Event Viewer | Views Windows security events |
| Sysmon | Monitors process and system activity |
| Python | Automates selected log analysis tasks |
| Git and GitHub | Version control and project sharing |
| VS Code | Project development and documentation |

## Overall Objective
Integrate these tools to build a controlled Windows security monitoring and incident investigation environment.
